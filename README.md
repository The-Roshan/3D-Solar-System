
# 🌠 3D Solar System with Glow

## 🚀 Overview
**3D Solar System with Glow** is an interactive and visually engaging web-based simulation of our solar system. Developed by **Roshan Kumar Prajapati**, the project showcases orbiting planets around a glowing sun, enhanced by a looping video background for an immersive space experience. Built entirely with **HTML**, **CSS**, and **JavaScript**, it's lightweight, responsive, and perfect for educational or visual showcase purposes.

---

## ✨ Features
- **Realistic Orbital Animation**  
  Planets revolve around the sun at different speeds using pure CSS animations.

- **Glowing Sun Centerpiece**  
  The sun features a glowing aura effect created with CSS for a radiant look.

- **Space-Themed Video Background**  
  A seamless, muted, looping video creates a deep space ambiance.

- **Responsive Design**  
  Works across all modern browsers and screen sizes, from mobile to desktop.

- **No External Libraries**  
  Pure HTML/CSS/JavaScript – no frameworks or 3D engines required.

## 🛠️ Setup Instructions

### 1. Clone the Repository
```bash
git clone https://github.com/The-Roshan/3d-solar-system.git
cd 3d-solar-system
```

### 2. Launch the Project
Open `index.html` directly in a web browser:
```bash
start index.html      # On Windows
open index.html       # On macOS
```

> ✅ Tip: Use **Live Server** in VS Code for smoother media playback (especially video).

---

## 🧩 Customization

You can easily tailor the project to your needs:

- **Change Planets**: Update colors or sizes in `styles.css`.
- **Replace Background**: Use a different `.mp4` file for your preferred galaxy or animation.
- **Add Features**: Extend with JavaScript to include planetary rotation, moon orbits, or tooltips.
- **Make it 3D**: Integrate with libraries like **Three.js** for real-time 3D effects.

## 🌍 Deployment

### GitHub Pages
1. Push your code to a GitHub repo.
2. Go to `Settings > Pages`.
3. Select the branch and root folder.
4. Visit `https://<your-username>.github.io/3d-solar-system/`.

- Drag and drop the project folder into the platform dashboard.
- Or connect your GitHub repository for continuous deployment.

## 📌 Notes

- Ensure that `background.mp4` is optimized for web use (compressed format recommended).
- Test on modern browsers (Chrome, Firefox, Edge) for best compatibility.
- Autoplaying videos may require the `muted` attribute due to browser restrictions.
